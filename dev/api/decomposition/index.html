FlowGeometries.Decomposition._block — Method
_block(grid, ranges, halo, execution) -> Block

The block of grid holding cells ranges with halo cells each side of every direction that has one. Coordinates, measure and mask are the grid's own values at those cells. Every direction of a block is bounded: across a periodic seam its halo continues the coordinate one period on. A block's type follows the grid's type alone, whichever directions are split.

FlowGeometries.Decomposition.split_grid — Function
split_grid(grid, backend; dims = (ndims(grid),), blocks = nothing, halo = 2) -> AbstractSplitGrid
split_grid(split; dims) -> AbstractSplitGrid

grid split into blocks along the directions dims, blocks[k] of them along dims[k], one block per rank of an MPIBackend (using MPI) or per worker of a DistributedBackend (using Distributed, FlowGeometries loaded on every worker). blocks = nothing divides the ranks over dims as MPI.Dims_create does, or the workers likewise. Block p of P along a direction of n cells holds cells (n(p-1))÷P + 1 : (np)÷P, the split PencilArrays makes.

Each block carries halo cells of its neighbours' each side of a split direction, wrapping across a periodic seam and stopping at a bounded end, so a stencil of up to halo nodes along that direction sees every sample it sees on the whole grid. A block holds at least halo cells.

The second form splits the same grid along other directions over the same processes, the pair redistribute! moves fields between.
